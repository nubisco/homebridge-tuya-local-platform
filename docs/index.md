## Homebridge Native

Seamless Apple HomeKit integration via Homebridge with full accessory lifecycle management and Config UI X support.

## 100% Local LAN

Communicates directly with devices using the Tuya protocol. No cloud servers, no internet dependency, no latency.

## 23 Device Types

Outlets, lights, dimmers, fans, blinds, climate, garage doors, valves, and more. Each with dedicated HomeKit mapping.

## Tuya Protocol v3.1 / 3.3 / 3.4

Full encryption and authentication support across all major Tuya LAN protocol versions.

## Adaptive Lighting

HomeKit Adaptive Lighting support on compatible tunable white and RGBTW light accessories.

## Energy Monitoring

Real-time voltage, current, and power readings on supported outlets and circuit breaker monitors.
